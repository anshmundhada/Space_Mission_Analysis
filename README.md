# Space_Mission_Analysis
🚀 Space Missions Analysis | Python Data Analytics Project

📌 Project Overview

This project focuses on analyzing historical space mission data to uncover meaningful insights about global space exploration. The analysis includes data cleaning, preprocessing, exploratory data analysis (EDA), visualization, and business insights using Python.

The objective was to identify launch trends, mission success rates, top-performing space organizations, launch site performance, rocket usage, mission costs, and temporal patterns over the years.

⸻

🎯 Objectives

* Analyze historical space mission data.
* Identify the most active space agencies and launch sites.
* Compare mission success, failure, and partial failure rates.
* Analyze mission costs across organizations and rockets.
* Study rocket usage and operational status.
* Discover launch trends over different years.
* Generate actionable insights using data visualization.

⸻

🛠️ Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook

⸻

📊 Project Workflow

🔹 Data Preparation

* Handled missing values
* Renamed columns for better readability
* Converted data types
* Converted launch dates into datetime format
* Extracted Year and Month from launch dates

🔹 Exploratory Data Analysis (EDA)

* Distribution analysis of mission costs
* Categorical analysis using value counts
* Histogram and Boxplot for outlier detection
* Statistical summary using descriptive analysis

🔹 Space Agency Analysis

* Most active launch organizations
* Company-wise successful missions
* Failed and partially failed mission analysis

🔹 Launch Site Analysis

* Most frequently used launch locations
* Success comparison across launch sites

🔹 Rocket Analysis

* Most frequently used rockets
* Active vs Retired rockets
* Rocket operational status analysis

🔹 Cost Analysis

* Average mission cost by organization
* Comparison of mission cost based on mission outcomes
* Identification of expensive missions

🔹 Time Series Analysis

* Launch frequency over the years
* Mission outcome trends over time
* Year-wise launch growth analysis

⸻

📈 Key Insights

* Identified the organizations conducting the highest number of space launches.
* Compared mission success, failure, and partial failure rates across companies.
* Discovered the most active launch sites worldwide.
* Identified the most frequently used rockets and their operational status.
* Analyzed mission costs to understand spending patterns among space agencies.
* Visualized yearly launch trends and mission outcomes to reveal long-term growth in space exploration.
